\# Mini SaaS



Sistema web de cadastro e gerenciamento de produtos.



\## Tecnologias

\- Python

\- Flask

\- SQLite

\- HTML e CSS

\- Git e GitHub



\## Funcionalidades

\- Cadastrar produtos

\- Listar produtos

\- Excluir produtos



\## Executar

1\. Ativar o ambiente virtual.

2\. Instalar as dependências.

3\. Executar python app.py.

4\. Acessar http://127.0.0.1:5000.
